# 🚗 Uber Analytics Dashboard 2024

## 📌 Project Overview
End-to-end data analytics project on 
Uber rideshare data.

## 🛠️ Tools Used
- Python (Pandas, Matplotlib, Seaborn)
- SQLite Database
- Power BI Desktop
- Jupyter Notebook

## 📁 Files
| File | Description |
|------|-------------|
| Uber_Cleaned.ipynb | Main analysis notebook |
| uber_Dashboard.pbix | Power BI dashboard |
| rideshare.db | SQLite database |
| schema.sql | Database schema |
| *.csv | Exported data tables |

## 📊 Dashboard Pages
- 🏠 Home
- 👥 Customer Analytics
- 🚗 Drivers Analytics
- 🚙 Vehicle Analytics

## 📈 Analysis Includes
- Trip Analysis
- Payment Analysis
- Driver & Rider Analysis
- ML Fare Prediction

users, drivers, riders, locations,
